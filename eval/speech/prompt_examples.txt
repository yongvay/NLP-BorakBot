# initial_prompt / prompt_ids candidates for Whisper.

# CRITICAL: these share NO sentences and no distinctive vocabulary with manifest.csv.
# Test topics are banking, licences, tax and Malaysian agencies -- so these deliberately
# use weather, media, sport and casual chat instead. Reusing test content here would
# make the model copy from its own context and inflate every WER number.
#
# Whisper caps the prompt at 224 tokens and truncates from the LEFT, so the most
# important examples go LAST. Descriptions like "this is rojak" do nothing -- only
# concrete examples in the exact orthography you want will bias the decoder.
